# Πώς συνδέεται ο ιστότοπος με το entclinic.gr

Ο ιστότοπος ζει σήμερα στο **https://dskiad.github.io/entclinic-website/**
και δημοσιεύεται αυτόματα με κάθε push στο `main`.

Αυτό το αρχείο περιγράφει τι χρειάζεται για να τον δει ο κόσμος στη δική σας
διεύθυνση. Δεν έχει γίνει τίποτε από αυτά — είναι οδηγίες για όταν αποφασίσετε.

---

## Πριν από οτιδήποτε: δύο πράγματα που δεν πρέπει να χαλάσουν

**1. Το email.** Οι εγγραφές `MX` του entclinic.gr στέλνουν τα μηνύματα του
`lmariolis@entclinic.gr`. Η σύνδεση με το GitHub αγγίζει **μόνο** εγγραφές `A`
και `CNAME`, ποτέ `MX` ή `TXT` του email. Αν κάποιος «καθαρίσει» τις εγγραφές
του domain, το email σταματά την ίδια στιγμή.

**2. Η κράτηση ραντεβού.** Το κουμπί «Κλείστε Ραντεβού» οδηγεί στο
`https://entclinic.gr/book-appointment/`, που φιλοξενείται στον **υπάρχοντα**
server (168.119.205.208), όχι στο GitHub. Δείτε την Επιλογή Β παρακάτω.

---

## Επιλογή Α — υποτομέας (χωρίς κανέναν κίνδυνο)

Π.χ. `new.entclinic.gr`. Ο υπάρχων ιστότοπος και η κράτηση ραντεβού μένουν
ακριβώς όπως είναι.

### 1. Στο DNS (panel φιλοξενίας)

Μία μόνο εγγραφή:

| Τύπος | Όνομα | Τιμή |
|---|---|---|
| CNAME | `new` | `dskiad.github.io.` |

Η τελεία στο τέλος χρειάζεται σε πολλά panel. Μην αγγίξετε τίποτε άλλο.

### 2. Στο GitHub

`github.com/dskiad/entclinic-website` → **Settings** → **Pages** →
*Custom domain* → γράψτε `new.entclinic.gr` → **Save**.

Το GitHub ελέγχει το DNS. Όταν εμφανιστεί πράσινο ✓, τσεκάρετε
**Enforce HTTPS**. Το πιστοποιητικό εκδίδεται μόνο του και θέλει από λίγα
λεπτά έως μερικές ώρες — αν το κουμπί είναι ακόμη γκρίζο, περιμένετε.

### 3. Στο repository

```
python3 tools/set-site-url.py https://new.entclinic.gr --cname
python3 tools/make-review-card.py
git add -A && git commit -m "Point the site at new.entclinic.gr" && git push
```

Το πρώτο ενημερώνει και τις 13 απόλυτες διευθύνσεις (προεπισκόπηση συνδέσμου,
δομημένα δεδομένα, sitemap, robots). Το δεύτερο ξαναφτιάχνει τις κάρτες QR,
που αλλιώς θα οδηγούν στην παλιά διεύθυνση.

## Επιλογή Β — το κύριο entclinic.gr

Η νέα σελίδα **αντικαθιστά** τον υπάρχοντα ιστότοπο.

### Πρώτα λύστε την κράτηση ραντεβού

Μόλις το `entclinic.gr` δείξει στο GitHub, το `/book-appointment/` **παύει να
υπάρχει**. Πριν αλλάξετε οτιδήποτε, βρείτε τι είναι σήμερα αυτή η σελίδα:

- Αν είναι υπηρεσία τρίτου (π.χ. Doctoranytime, Calendly, ένα plugin
  κρατήσεων), πάρτε τη δική της διεύθυνση και αλλάξτε τους 3 συνδέσμους στο
  `index.html` ώστε να δείχνουν κατευθείαν εκεί.
- Αν είναι δική σας σελίδα στο WordPress, πρέπει να μεταφερθεί κάπου αλλού —
  π.χ. σε υποτομέα `book.entclinic.gr` που μένει στον παλιό server.

**Μην κάνετε την αλλαγή DNS όσο δεν έχει απαντηθεί αυτό.**

### 1. Στο DNS

Αντικαταστήστε την εγγραφή `A` του `@` (168.119.205.208) με τέσσερις:

| Τύπος | Όνομα | Τιμή |
|---|---|---|
| A | `@` | `185.199.108.153` |
| A | `@` | `185.199.109.153` |
| A | `@` | `185.199.110.153` |
| A | `@` | `185.199.111.153` |

Και για το `www`:

| Τύπος | Όνομα | Τιμή |
|---|---|---|
| CNAME | `www` | `dskiad.github.io.` |

Προαιρετικά, για IPv6, τέσσερις εγγραφές `AAAA` στο `@`:
`2606:50c0:8000::153`, `2606:50c0:8001::153`, `2606:50c0:8002::153`,
`2606:50c0:8003::153`.

**Τις εγγραφές MX μην τις αγγίξετε.**

### 2 και 3

Ίδια με την Επιλογή Α, με `https://entclinic.gr`.

## Μετά τη μεταφορά

- Το `dskiad.github.io/entclinic-website` ανακατευθύνει μόνο του στη νέα
  διεύθυνση. Οι παλιοί σύνδεσμοι δεν σπάνε.
- **Τυπώστε ξανά τις κάρτες QR.** Οι παλιές δείχνουν στην παλιά διεύθυνση·
  θα λειτουργούν μέσω ανακατεύθυνσης, αλλά μια κάρτα με ξένο domain πάνω της
  δεν είναι καλή εικόνα.
- Στο **Google Search Console** προσθέστε τη νέα διεύθυνση και δηλώστε το
  `sitemap.xml`.
- Δοκιμάστε την προεπισκόπηση συνδέσμου: στείλτε το link στον εαυτό σας σε
  Viber ή Messenger και δείτε ότι εμφανίζεται η κάρτα με το πορτραίτο.

## Προστασία από κατάληψη υποτομέα

Στον **λογαριασμό** σας (όχι στο repository): **Settings** → **Pages** →
*Add a verified domain*. Το GitHub δίνει μια εγγραφή `TXT` για να προσθέσετε
στο DNS. Αυτό εμποδίζει κάποιον τρίτο να «πιάσει» τον υποτομέα σας σε δικό του
repository αν κάποτε τον αφήσετε ελεύθερο. Δεν είναι υποχρεωτικό, είναι σωστό.

## Ασφάλεια

Τα διαπιστευτήρια του panel φιλοξενίας δεν χρειάζονται ποτέ για τη σύνδεση με
το GitHub, και δεν πρέπει να στέλνονται σε συνομιλίες, email ή μηνύματα.
Αν έχουν σταλεί, αλλάξτε τον κωδικό και ενεργοποιήστε διπλό παράγοντα.
